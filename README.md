A learning repository exploring the connection between **Molecular Dynamics, Python data analysis, and Machine Learning**.

## What I'm learning

* GROMACS and Molecular Dynamics
* Energy minimization, NVT, NPT, and production MD
* Trajectory analysis
* RDF and other MD analyses
* Python data analysis and visualization
* Machine Learning and Deep Learning for MD data

```text
MD Simulation
     ↓
GROMACS Data
     ↓
Python Analysis & Visualization
     ↓
Machine Learning

```

This repository documents my progress and practical experiments while learning **MD + Python + ML**.
